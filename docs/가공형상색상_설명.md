# 가공 형상 색상 rule

대상 : `rules/MachiningFeatureColor.iLogicVb`

조립도 안의 **가공품**에서 구멍과 나사를 종류별로 다른 색으로 칠해 한눈에
구분하는 rule 입니다. 확인용이라 **부품 파일은 저장하지 않고**, 같은 rule 로
**원래 색으로 되돌릴 수 있습니다.**

## 실행

조립도(또는 부품)를 열고 rule 을 실행하면 먼저 이렇게 묻습니다.

```
무엇을 할까요?

[예]       가공품의 구멍·나사에 색 칠하기
[아니오]   원래 색으로 되돌리기
[취소]     그만두기
```

[예] 를 누르면 칠할 가공품 목록과 제외된 부품 수를 보여주고 한 번 더 확인합니다.

## 색

| 종류 | 색 | 대상 |
|---|---|---|
| 홀(드릴) | 파랑 | 구멍 피처 - 드릴 |
| 카운터보어 | 주황 | 구멍 피처 - 카운터보어 |
| 카운터싱크 | 초록 | 구멍 피처 - 카운터싱크 |
| 스폿페이스 | 보라 | 구멍 피처 - 스폿페이스 |
| 탭 | 빨강 | 구멍 피처 - 탭 구멍 |
| 나사산 | 노랑 | 나사(Thread) 피처 |

색은 rule 위쪽 설정에서 `"빨강:230,0,0"` 처럼 `이름:R,G,B` 로 바꿉니다.
이름은 결과 창에 보여주는 용도입니다.

## 가공품을 고르는 방법

부품번호 **또는** 파일명이 아래 두 조건에 **모두** 맞으면 가공품입니다.

1. 설정한 접두어로 시작 — 기본값 `GMKS-`
2. 끝이 `-숫자` 이고, 뒤에 리비전 문자가 2개까지 붙을 수 있음

| 번호 | 판정 |
|---|---|
| `GMKS-ST2601-ETR01-59` | 가공품 |
| `GMKS-ST2601-ETR01-59A` | 가공품 |
| `GMKS-ST2601-ETR01-059AB` | 가공품 |
| `GMKS-ST2601-ETR01` | 제외 (끝이 번호가 아님) |
| `GMKS-ST2601-ETR01-59ABC` | 제외 (리비전 3글자) |
| `MISUMI-SFJ10-100` | 제외 (접두어 다름) |
| `M6x20` | 제외 |

- Content Center 부품은 번호와 관계없이 제외합니다.
- 부품 하나만 열고 실행하면 번호와 관계없이 그 부품을 칠합니다.
- 접두어가 여러 개면 `PREFIXES = "GMKS-, ABC-"` 처럼 쉼표로 적습니다.
- 칠할 가공품이 하나도 없으면, 제외된 부품 목록을 보여주므로 규칙을 고칠 때
  참고하시면 됩니다.

## 어떤 면을 칠하나

- **구멍 피처가 만든 면 전체** — 카운터보어면, 드릴면, 끝 원뿔면 모두
- **탭 구멍은 종류와 관계없이 탭 색** — 탭 + 카운터싱크도 빨강.
  카운터싱크 색이 먼저였으면 좋겠으면 `TAP_OVER_TYPE = False`
- **나사(Thread) 피처** — 나사가 걸린 면만. 구멍 색 위에 덮어 칠합니다.
- **구멍을 패턴/미러한 것** — 원본 구멍과 같은 색
  - 패턴 안에 구멍과 다른 피처(돌출 등)가 섞여 있거나, 종류가 다른 구멍이
    섞여 있으면 칠하지 않고 결과 창에 이름을 알려줍니다.
  - 구멍과 나사 피처를 같이 패턴한 것은 구멍 색으로 칠합니다.
- **칠하지 않는 것** — 돌출 컷/회전 컷으로 판 원통 구멍, 조립품 피처로 판
  구멍, 억제된 피처

## 원래대로 돌아가는 방법

칠하기 전에 면마다 원래 색 설정을 속성(Attribute)으로 적어 둡니다.
[원래대로] 는 그 기록대로 되돌리고, 이 rule 이 부품 안에 만든 색
(`HFC_DRILL`, `HFC_TAP` …)을 지웁니다.

- 원래 면에 따로 색을 지정해 두었으면 그 색으로 돌아갑니다.
- 두 번 칠해도 처음 색을 기억합니다.
- 메모리에 올라와 있는 모든 문서를 찾으므로, 다른 조립도를 열고 실행해도
  됩니다.

## 저장하지 않는 방법

칠하기 전에 **저장 안 된 변경이 없던 부품**은 칠한 뒤 "변경 없음" 으로
표시합니다 (`KEEP_CLEAN`).

- 조립도를 저장(Ctrl+S)해도 부품은 저장되지 않습니다.
- 조립도를 닫아도 부품을 저장하라고 묻지 않고, 색은 그냥 사라집니다.
- Vault 체크아웃이 필요 없습니다.
- 이미 고쳐 두고 저장 안 한 부품은 그 변경을 지키기 위해 손대지 않습니다.
  이런 부품은 닫을 때 저장할지 물어보므로 그때는 **[아니오]** 를 누르거나,
  먼저 [원래대로] 를 실행하세요.

> ★ **색이 칠해진 채로 부품을 고치고 저장하면 색도 같이 저장됩니다.**
> 부품을 고치기 전에 [원래대로] 를 먼저 실행하세요.
> 실수로 저장했더라도 [원래대로] 로 되돌린 뒤 다시 저장하면 됩니다.
> 그런 부품은 [원래대로] 결과 창에 "칠한 색이 파일에 저장되어 있었습니다" 로
> 따로 알려줍니다.

## 조립도에서 색을 덮어쓴 부품

조립도에서 부품에 색을 지정해 두었으면 부품 면 색이 가려 보이지 않습니다.
그런 가공품이 있으면 뷰 표현 **"가공색상 확인(임시)"** 을 새로 만들어 그 안에서만
덮어쓴 색을 풀어 줍니다. 원래 뷰 표현은 건드리지 않습니다.

[원래대로] 를 실행하면 원래 뷰 표현으로 돌아가고 임시 뷰 표현을 지웁니다.
이 동작이 필요 없으면 `SHOW_THROUGH_ASM_COLOR = False`.

## 설정

| 설정 | 기본값 | 뜻 |
|---|---|---|
| `PREFIXES` | `"GMKS-"` | 가공품 번호 접두어. 비우면 접두어는 안 봄 |
| `MAX_REV_LETTERS` | `2` | 번호 끝 리비전 문자 최대 개수 |
| `C_DRILL` ~ `C_THREAD` | 위 표 | 종류별 색 `이름:R,G,B` |
| `TAP_OVER_TYPE` | `True` | 탭 구멍은 종류와 관계없이 탭 색 |
| `SHOW_THROUGH_ASM_COLOR` | `True` | 조립도 색 덮어쓰기를 임시 뷰 표현에서 풀기 |
| `KEEP_CLEAN` | `True` | 칠한 부품을 "변경 없음" 으로 표시 |
| `LIST_MAX` | `12` | 확인 창 목록 최대 줄 수 |

## 처음 써 보실 때

이 rule 은 인벤터가 없는 환경에서 만들어 **실제 인벤터에서 컴파일·실행해 보지
못했습니다.** 번호 판정 로직만 따로 옮겨 위 표의 번호로 확인했습니다.
아래 순서로 작은 조립도에서 먼저 확인해 주세요.

1. 가공품 2~3개짜리 작은 조립도를 열고 [예] 로 칠하기
2. 드릴 / 카운터보어 / 탭 / 나사산이 서로 다른 색으로 보이는지
3. 조립도를 닫을 때 부품을 저장하라고 묻지 않는지
4. 다시 열고 칠한 뒤 [아니오] 로 되돌렸을 때 원래 색이 되는지
5. Vault 에 체크인된 부품에서 "체크아웃할까요?" 창이 뜨는지
   (뜨면 알려주세요. 인벤터 Vault 옵션에 따라 다릅니다)

컴파일 오류가 나면 오류 창의 **줄 번호와 메시지**를 알려주시면 고치겠습니다.
