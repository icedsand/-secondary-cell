# 가공 형상 색상 rule

대상 : `rules/MachiningFeatureColor.iLogicVb`

조립도 안의 **가공품**에서 구멍과 나사를 종류별로 다른 색으로 칠해 한눈에
구분하는 rule 입니다. 확인용이라 **부품 파일은 저장하지 않고**, 같은 rule 로
**원래 색으로 되돌릴 수 있습니다.**

## 실행

조립도(또는 부품)를 열고 rule 을 실행하면 먼저 이렇게 묻습니다.

```
무엇을 할까요?

[예]       가공품의 구멍·나사에 색 칠하기
[아니오]   원래 색으로 되돌리기
[취소]     그만두기
```

[예] 를 누르면 칠할 가공품 목록과 제외된 부품 수를 보여주고 한 번 더 확인합니다.

## 색

| 종류 | 색 | 대상 |
|---|---|---|
| 홀(드릴) | 파랑 | 구멍 피처 - 드릴 |
| 카운터보어 | 주황 | 구멍 피처 - 카운터보어 |
| 카운터싱크 | 초록 | 구멍 피처 - 카운터싱크 |
| 스폿페이스 | 보라 | 구멍 피처 - 스폿페이스 |
| 탭 | 빨강 | 구멍 피처 - 탭 구멍 |
| 나사산 | 노랑 | 나사(Thread) 피처 |

색은 rule 위쪽 설정에서 `"빨강:230,0,0"` 처럼 `이름:R,G,B` 로 바꿉니다.
이름은 결과 창에 보여주는 용도입니다.

## 가공품을 고르는 방법

부품번호 **또는** 파일명이 아래 두 조건에 **모두** 맞으면 가공품입니다.

1. 설정한 접두어로 시작 — 기본값 `GMKS-`
2. 끝이 `-숫자` 이고, 뒤에 리비전 문자가 2개까지 붙을 수 있음

| 번호 | 판정 |
|---|---|
| `GMKS-ST2601-ETR01-59` | 가공품 |
| `GMKS-ST2601-ETR01-59A` | 가공품 |
| `GMKS-ST2601-ETR01-059AB` | 가공품 |
| `GMKS-ST2601-ETR01-33A_MIR` | 가공품 (미러 부품, `_MIR` 은 떼고 봄) |
| `GMKS-ST2601-ETR01` | 제외 (끝이 번호가 아님) |
| `GMKS-ST2601-ETR01-59ABC` | 제외 (리비전 3글자) |
| `MISUMI-SFJ10-100` | 제외 (접두어 다름) |
| `M6x20` | 제외 |

- **미러 부품** — 조립품 [구성요소 미러] 로 만든 부품은 이름 끝에 `_MIR` 이
  붙습니다. 이 꼬리를 떼고 번호를 봅니다. 미러 부품에 따로 추가한 구멍/탭도
  칠합니다. (원본에서 넘어온 구멍은 원본 부품을 칠하면 그 색이 따라옵니다)
  다른 꼬리도 있으면 `SUFFIXES = "_MIR, _R"` 처럼 쉼표로 적습니다.
- Content Center 부품은 번호와 관계없이 제외합니다.
- 부품 하나만 열고 실행하면 번호와 관계없이 그 부품을 칠합니다.
- 접두어가 여러 개면 `PREFIXES = "GMKS-, ABC-"` 처럼 쉼표로 적습니다.
- 칠할 가공품이 하나도 없으면, 제외된 부품 목록을 보여주므로 규칙을 고칠 때
  참고하시면 됩니다.

## 어떤 면을 칠하나

- **구멍 피처가 만든 면 전체** — 카운터보어면, 드릴면, 끝 원뿔면 모두
- **탭 구멍은 종류와 관계없이 탭 색** — 탭 + 카운터싱크도 빨강.
  카운터싱크 색이 먼저였으면 좋겠으면 `TAP_OVER_TYPE = False`
- **나사(Thread) 피처** — 나사가 걸린 면만. 구멍 색 위에 덮어 칠합니다.
- **구멍을 패턴/미러한 것** — 원본 구멍과 같은 색
  - 패턴 안에 구멍과 다른 피처(돌출 등)가 섞여 있거나, 종류가 다른 구멍이
    섞여 있으면 칠하지 않고 결과 창에 이름을 알려줍니다.
  - 구멍과 나사 피처를 같이 패턴한 것은 구멍 색으로 칠합니다.
- **칠하지 않는 것** — 돌출 컷/회전 컷으로 판 원통 구멍, 조립품 피처로 판
  구멍, 억제된 피처

## 속도 (부품 600개 조립도에서 3~10분 걸리던 것 개선)

처음 판이 느렸던 이유는 두 가지였습니다.

| | 처음 판 | 지금 |
|---|---|---|
| 칠하기 | 면을 하나하나 칠함. 면 색을 바꿀 때마다 인벤터가 모델을 갱신 | 구멍/패턴 **피처에 한 번** 칠함. 피처가 만든 면 전체에 들어감 |
| 되돌리기 | 메모리의 **모든 부품**(볼트 같은 표준품 포함)에서 칠한 면을 찾음 (면 찾기가 매우 느림) | rule 이 칠한 표시가 있는 부품만 보고, 피처 목록에서 찾음. 면 찾기는 면을 따로 칠한 부품에만 함 |

- 카운터보어 구멍 하나는 면이 3~5개, 구멍 50개짜리 패턴은 면이 200개가
  넘습니다. 이제 어느 쪽이든 색을 **한 번만** 바꿉니다.
- 나사산과, 원래 면에 따로 색이 지정된 면은 피처 색이 가려지므로 그 면만
  예전처럼 면 단위로 칠합니다.
- 피처 단위로 칠하지 못하는 피처가 있으면 그 피처만 면 단위로 칠합니다.
- 칠하는 동안과 되돌리는 동안 **진행 막대**(`120 / 600   부품이름`)를 보여주고,
  결과 창에 **걸린 시간**을 보여줍니다.
- 처음 판으로 칠해 둔 부품도 그대로 되돌릴 수 있습니다 (그 부품만 면을 찾음).

## 원래대로 돌아가는 방법

칠하기 전에 피처/면마다 원래 색 설정을 속성(Attribute)으로 적어 둡니다.
[원래대로] 는 그 기록대로 되돌립니다.

- 원래 면에 따로 색을 지정해 두었으면 그 색으로 돌아갑니다.
- 두 번 칠해도 처음 색을 기억합니다.
- **지금 연 조립도와 그 안의 부품만** 되돌립니다. 다른 조립도에만 들어 있는
  칠한 부품은 건드리지 않고, 결과 창에 개수만 알려줍니다. 그 조립도는 따로
  열고 [원래대로] 를 실행하세요.
  (한때 메모리에 열린 모든 문서를 되돌려서, 따로 열어 둔 다른 조립도의 구멍
  색까지 지운 적이 있어 고쳤습니다)
- 부품 색은 부품 파일 안에 들어가므로, **두 조립도에 같이 들어 있는 부품**은
  어느 쪽에서 칠하거나 되돌려도 양쪽에 똑같이 보입니다.
- 이 rule 이 부품 안에 만든 색(`HFC_DRILL`, `HFC_TAP` …)은 **지우지 않고**
  남겨 두었다가 다시 칠할 때 씁니다. 아무 면도 쓰지 않는 색이라 화면에는
  보이지 않고, 부품을 저장하지 않으면 파일에도 남지 않습니다.

### 되돌리지 못한 피처/면이 생기던 문제 (고침)

[원래대로] 결과에 "되돌리지 못한 피처/면 : 190개" 가 나왔습니다.

- 칠하기 전에 읽어 둔 원래 색 설정 값을 그대로 다시 넣는데, 인벤터가 그 값을
  거부하는 피처/면이 있었습니다.
- 그리고 하나라도 못 되돌린 부품도 "칠했음" 표시를 지워 버려서, [원래대로] 를
  다시 실행해도 그 부품을 찾지 못했습니다.

고친 내용

- 원래 값이 거부되면 "부품 색 따르기" 를 넣어 보고, 그것도 안 되면 인벤터가
  가진 다른 색 출처 값을 차례로 넣어 봅니다. 덮어쓴 색이 실제로 풀렸는지까지
  확인합니다.
- 못 되돌린 것이 있는 부품은 표시를 남겨 둡니다. [원래대로] 를 한 번 더
  실행하면 남은 것만 다시 시도합니다.
- 앞 판에서 표시가 지워진 부품도, 이 rule 의 색(`가공색 - …`)이 남아 있으면
  찾아서 되돌립니다.
- 다 되돌린 부품에는 "되돌림 완료" 표시를 남겨, 다음 [원래대로] 에서는
  건너뜁니다 (되돌리기가 다시 느려지지 않도록).
- 결과 창에 **실패 이유**(인벤터 오류 메시지)를 피처 종류와 함께 보여줍니다.

### 되돌린 뒤 다시 칠하면 칠해지지 않던 문제 (고침)

결과 창의 실패 이유가 `색 만들기 : 매개 변수가 틀립니다 (0x80070057)` 였습니다.

- 인벤터는 새 색의 **표시 이름**(`가공색 - 탭`)이 문서 안에 이미 있으면
  만들기를 거부합니다. 이름(`HFC_TAP`)만 바꿔서는 소용이 없었습니다.
- 그리고 처음 칠할 때 만든 색을 rule 이 다시 찾지 못했습니다. 이름으로만
  찾았는데, 인벤터가 준 이름을 그대로 쓰지 않은 것으로 보입니다.
- 그래서 처음 칠하기는 되고, 같은 부품을 다시 칠하면 "있는 색은 못 찾고,
  같은 표시 이름으로 새로 만들다 실패" 했습니다.

고친 내용

- 남아 있는 색을 이름과 **표시 이름 둘 다**로 찾아 다시 씁니다.
- 새로 만들 때는 이름과 표시 이름이 모두 겹치지 않는 번호를 찾습니다
  (`가공색 - 탭 (2)`).
- 남아 있던 색으로 하나도 칠하지 못하면 새 색을 만들어 한 번 더 칠합니다.
- 그래도 실패하면 결과 창 아래에 **실패 이유**(인벤터 오류 메시지)를
  보여줍니다.
- 이 rule 이 만든 색은 [원래대로] 에서 지우지 않고 다음에 다시 씁니다.
  아무 면도 쓰지 않는 색이라 보이지 않고, 저장하지 않으면 파일에도 남지
  않습니다.
- 임시 뷰 표현도 이름이 막히면 `가공색상 확인(임시) 2` 처럼 번호를 붙여
  만들고, [원래대로] 에서 번호 붙은 것까지 모두 지웁니다.

## 저장하지 않는 방법

칠하기 전에 **저장 안 된 변경이 없던 부품**은 칠한 뒤 "변경 없음" 으로
표시합니다 (`KEEP_CLEAN`).

- 조립도를 저장(Ctrl+S)해도 부품은 저장되지 않습니다.
- 조립도를 닫아도 부품을 저장하라고 묻지 않고, 색은 그냥 사라집니다.
- Vault 체크아웃이 필요 없습니다.
- 이미 고쳐 두고 저장 안 한 부품은 그 변경을 지키기 위해 손대지 않습니다.
  이런 부품은 닫을 때 저장할지 물어보므로 그때는 **[아니오]** 를 누르거나,
  먼저 [원래대로] 를 실행하세요.

> ★ **색이 칠해진 채로 부품을 고치고 저장하면 색도 같이 저장됩니다.**
> 부품을 고치기 전에 [원래대로] 를 먼저 실행하세요.
> 실수로 저장했더라도 [원래대로] 로 되돌린 뒤 다시 저장하면 됩니다.
> 그런 부품은 [원래대로] 결과 창에 "칠한 색이 파일에 저장되어 있었습니다" 로
> 따로 알려줍니다.

## 조립도에서 색을 덮어쓴 부품

조립도에서 부품에 색을 지정해 두었으면 부품 면 색이 가려 보이지 않습니다.
그런 가공품이 있으면 뷰 표현 **"가공색상 확인(임시)"** 을 새로 만들어 그 안에서만
덮어쓴 색을 풀어 줍니다. 원래 뷰 표현은 건드리지 않습니다.

**하위 조립품 전체에 색을 지정한 경우**도 그 안의 부품이 모두 가려집니다.
처음 판은 부품 쪽만 풀어서, 부품을 따로 열면 색이 보이는데 조립도에서는
안 보였습니다. 이제 부품부터 맨 위 하위 조립품까지 덮어쓴 색을 **위쪽부터
차례로** 풉니다. 그래서 임시 뷰 표현에서는 그 하위 조립품의 다른 부품들도
조립도에서 준 색 대신 원래 부품 색으로 보입니다.

결과 창의 "풀었습니다 / 풀지 못함" 개수는 부품 자신과 위쪽 하위 조립품
어디에도 덮어쓴 색이 남지 않았을 때만 "풀었습니다" 로 셉니다. 풀지 못한
것은 배치 경로(`하위조립:1\부품:3`)를 보여줍니다.

[원래대로] 를 실행하면 원래 뷰 표현으로 돌아가고 임시 뷰 표현을 지웁니다.
이 동작이 필요 없으면 `SHOW_THROUGH_ASM_COLOR = False`.

## 설정

| 설정 | 기본값 | 뜻 |
|---|---|---|
| `PREFIXES` | `"GMKS-"` | 가공품 번호 접두어. 비우면 접두어는 안 봄 |
| `MAX_REV_LETTERS` | `2` | 번호 끝 리비전 문자 최대 개수 |
| `C_DRILL` ~ `C_THREAD` | 위 표 | 종류별 색 `이름:R,G,B` |
| `TAP_OVER_TYPE` | `True` | 탭 구멍은 종류와 관계없이 탭 색 |
| `SHOW_THROUGH_ASM_COLOR` | `True` | 조립도 색 덮어쓰기를 임시 뷰 표현에서 풀기 |
| `KEEP_CLEAN` | `True` | 칠한 부품을 "변경 없음" 으로 표시 |
| `LIST_MAX` | `12` | 확인 창 목록 최대 줄 수 |

## 처음 써 보실 때

이 rule 은 인벤터가 없는 환경에서 만들어 **실제 인벤터에서 컴파일·실행해 보지
못했습니다.** 번호 판정 로직만 따로 옮겨 위 표의 번호로 확인했습니다.
아래 순서로 작은 조립도에서 먼저 확인해 주세요.

1. 가공품 2~3개짜리 작은 조립도를 열고 [예] 로 칠하기
2. 드릴 / 카운터보어 / 탭 / 나사산이 서로 다른 색으로 보이는지
3. 조립도를 닫을 때 부품을 저장하라고 묻지 않는지
4. 다시 열고 칠한 뒤 [아니오] 로 되돌렸을 때 원래 색이 되는지
5. Vault 에 체크인된 부품에서 "체크아웃할까요?" 창이 뜨는지
   (뜨면 알려주세요. 인벤터 Vault 옵션에 따라 다릅니다)

컴파일 오류가 나면 오류 창의 **줄 번호와 메시지**를 알려주시면 고치겠습니다.
